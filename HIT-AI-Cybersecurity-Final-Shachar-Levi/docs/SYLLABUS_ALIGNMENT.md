# התאמת הפרויקט לסילבוס

## נושא מדויק

**זיהוי קישורי פישינג בהודעות דוא״ל באמצעות למידת מכונה, Explainable AI ושילוב התראות ב-SOC.**

גרסה 1 מנתחת את הקישור שמופיע בהודעת הדוא״ל. גרסה 2 המתוכננת תוכל לשלב גם מאפייני טקסט של ההודעה.

| דרישה או נושא בסילבוס | מימוש בפרויקט |
|---|---|
| פיתוח מערכת הגנת סייבר מבוססת AI | Pipeline המסווג קישור כלגיטימי או פישינג ומייצר התראה |
| זיהוי הודעות פישינג באמצעות AI | ניתוח רכיב הקישור בהודעת הדוא״ל; הרחבת NLP מתוכננת |
| למידת מכונה קלאסית | מודל Random Forest על 30 מאפיינים |
| Python ו-JupyterLab | קוד Python ו-Notebook הדגמה |
| מאגר נתונים אמיתי | UCI Phishing Websites, ‏11,055 רשומות |
| ניתוח והסבר תוצאות | Accuracy, Precision, Recall, F1, ROC-AUC ומטריצת בלבול |
| Explainable AI | Permutation Importance והצגת המאפיינים המשפיעים |
| הרחבה חכמה ל-SOC | יצירת התראות לדוגמה עם ציון סיכון וראיות |
| MITRE ATT&CK | מיפוי ל-T1566.002 Spearphishing Link |
| Responsible AI / Safe AI | מגבלות, פיקוח אנושי וניהול סיכונים לפי NIST AI RMF |
| צינור עיבוד מבוסס AI | טעינה, עיבוד, חלוקה, אימון, הערכה, הסבר והתראה |

## נקודות שיש לאשר מול המרצה

1. האם ניתן לבצע את הפרויקט לבד, משום שבסילבוס הוא מוגדר כפרויקט קבוצתי.
2. האם גרסה המתמקדת בקישורי פישינג מספקת, או שנדרשת גם שכבת NLP על טקסט ההודעה.
3. האם נדרש שימוש בפועל ב-NVIDIA Morpheus/GPU, או שהוא בגדר הרחבה מומלצת.
