# Data

הפרויקט משתמש במאגר **Phishing Websites** של UCI Machine Learning Repository.

- DOI: https://doi.org/10.24432/C51W2X
- גודל: 11,055 רשומות, 30 מאפיינים מספריים ומשתנה מטרה.
- רישיון: CC BY 4.0.
- המאגר כולל מאפיינים שחולצו מראש; הקוד אינו מבקר בכתובות אינטרנט חשודות.

יש לצטט את המקור בכל שימוש אקדמי. קובץ הנתונים מצורף לצורך שחזור הניסוי.
