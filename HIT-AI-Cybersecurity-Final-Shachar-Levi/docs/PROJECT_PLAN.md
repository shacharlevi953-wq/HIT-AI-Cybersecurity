# תוכנית עבודה

1. **הגדרת הבעיה** — סיווג אתר כפישינג או לגיטימי על בסיס מאפייני URL ודף.
2. **בסיס נתונים** — UCI Phishing Websites, כולל בדיקת איכות והגדרת משתנה מטרה.
3. **מודל בסיס** — Random Forest עם חלוקת train/test משוכבת.
4. **הערכה** — Accuracy, Precision, Recall, F1, ROC-AUC ומטריצת בלבול.
5. **Explainable AI** — Permutation Importance לזיהוי המאפיינים המשפיעים.
6. **הקשר סייבר** — מיפוי ל-MITRE ATT&CK T1566.002 ויצירת התראות SOC.
7. **Responsible AI** — ניהול סיכונים לפי NIST AI RMF: הטיות, drift, פרטיות ופיקוח אנושי.
8. **הרחבה** — השוואה למאגר עדכני ולמודל נוסף, ואז עדכון הדוח והמצגת.
