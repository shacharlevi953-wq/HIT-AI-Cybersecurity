# סטטוס ארבע המעבדות

הדרישות אותרו במאגר הקורס של המרצה. נכון לעדכון זה, אף מעבדה עדיין לא הוגשה; אפשר להשלים את כולן מתוך ההנחיות הקיימות.

| מעבדה | נושא | סטטוס נוכחי | תוצר נדרש | פעולה הבאה |
|---|---|---|---|---|
| 1 | מיפוי דוח CTI ל-MITRE ATT&CK | טרם הוגשה; ההנחיות אותרו | `lab1.md` עם סיכום מתקפה, תרשים ומיפוי טקטיקות/טכניקות | לבחור דוח CTI אמין ולבצע את המיפוי |
| 2 | זיהוי אנומליות בלוגים | טרם הוגשה; Notebook ותשתית קיימים במאגר הקורס | Notebook מלא: EDA, Isolation Forest, Autoencoder, השוואה וניתוח אנושי | להריץ את סביבת Docker ולהשלים את Notebook ההשוואה |
| 3 | סוכן LLM ושימוש בכלי | טרם הוגשה; תבנית קיימת במאגר הקורס | `app.py` ו-`README.md` באנגלית, כולל לפחות כלי Python אחד | לבחור סוכן פשוט, לממש ולתעד אותו |
| 4 | תהליך עבודה הגנתי/אדברסרי עם סוכני LLM | טרם הוגשה; תבנית קיימת במאגר הקורס | Workflow של לפחות שני רכיבים, נקודת החלטה, קוד ותיעוד באנגלית | לבנות Policy Gate לסוכן סייבר ולבדוק תרחישים מורשים/אסורים |

## סדר עבודה מוצע

1. מעבדה 1 — הקצרה ביותר וניתנת להגשה ב-Markdown ללא סביבת הרצה מורכבת.
2. מעבדה 3 — מימוש ממוקד של סוכן וכלי אחד.
3. מעבדה 4 — הרחבת רעיון מעבדה 3 ל-Workflow עם בקרה.
4. מעבדה 2 — הכבדה ביותר חישובית ותיעודית, ולכן כדאי להקדיש לה זמן נפרד.

לא יוצגו מעבדות כ״הושלמו״ לפני שהקוד והתוצרים הורצו ונבדקו בפועל.
