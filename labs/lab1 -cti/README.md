## Summary

Storm-2372 used device code phishing to steal valid OAuth access and refresh tokens. The actor posed as a trusted person, sent fake meeting invitations, gained cloud access, searched and exfiltrated email through Microsoft Graph, and expanded the campaign through compromised internal accounts.
